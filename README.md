# 🎓 EduPath - AI Learning Agent

## What it does
EduPath analyzes your resume, identifies skill gaps, and creates personalized 4-week learning plans.

## Features
✅ Resume parsing  
✅ Skill gap analysis  
✅ Personalized learning roadmaps  
✅ Progress tracking  
✅ AI tutor chat  

## Tech Stack
- Streamlit (UI)
- LangChain (AI Agent)
- Ollama with Qwen2.5 (Local LLM)
- PyPDF (Document parsing)

## How to Run Locally

1. Install Python 3.10+
2. Install Ollama: https://ollama.ai
3. Pull the model:
   ```bash
